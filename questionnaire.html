Before You Start

A strong brief should feel specific, not overwhelming.

Why answer the questionnaire before payment?

It helps you think through the song before checkout, and it gives us the details needed to make a more personal first draft.

What if I am not sure about the package yet?

Start with the brief anyway. You can choose the package afterward based on delivery timing, file needs, and how many revisions you want included.

Can I add more details later?

Yes. The brief captures the essentials first, and we can follow up if anything is missing before production starts.
